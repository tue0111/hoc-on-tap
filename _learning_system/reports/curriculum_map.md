## Concept backbone that the corpus actually supports

NLKT taught order (OBSERVED, not rewritten):

```
C1  Bản chất / lĩnh vực / môi trường kế toán
C2  BCTC (BCĐKT, KQKD, LCTT, thuyết minh) + phương trình kế toán + nguyên tắc
C3  Tài khoản (Nợ/Có) → ghi sổ kép → định khoản → đối chiếu
C4  Bút toán điều chỉnh (trả trước, khấu hao, dồn tích) → kết chuyển → TK↔BCTC
C5  Chứng từ → sổ sách → tổ chức công tác
C6  HTTT / CNTT
```

KTTC1 applies that machinery to **current assets**: tiền / phải thu / HTK, using TT 200 account numbers.

KTTC2 continues into **TSCĐ** and **nợ phải trả** (files present); VCSH and KQKD advertised only.

Cost accounting present chain: phân loại (trực tiếp/gián tiếp) → theo công việc → theo quy trình. Allocation as its own chapter is advertised and missing.

NHTM: Ch3 tổng quan cấp tín dụng is an **explicit** foundation for Ch4 cho vay.
