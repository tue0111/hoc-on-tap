# Explain / solve from curriculum

## Explain

1. Run course-context + curriculum-retrieval.
2. Quote lecturer_definition and textbook_definition separately if both exist.
3. List OBSERVED prerequisites from the graph. Do not add “common sense” prereqs.
4. Give one taught example if an exercise/source contains one.
5. If sources conflict, show both. Do not silently correct the lecturer.

## Solve

1. Identify the taught procedure (journal, costing, ratio, etc.) from sources.
2. Show steps in the order the course teaches them.
3. Map each number to an account/term used in the course.
4. If the course has a solution file, compare; do not overwrite it.
5. If the method is not in the corpus, say UNKNOWN. Do not import a generic method.

## Forbidden

- Inventing VAS/IFRS citations not in the source.
- Filling missing steps from memory when the chapter extract is empty/scanned.
